# Dashboard maestro (System)

`dashboard-maestro.html` es el dashboard maestro de TT. Estilo: vidrio redondeado, en blanco y negro.

Recorrido: `proyectos.html` → System → `system.html` (PIN de 4 números) → `dashboard.html`, que lo carga protegido desde `/sistema/dashboard-maestro.html`.

El dashboard anterior está en `~/TDT_REVISION/dashboard-maestro-conceptual-2026-09-23/`.
