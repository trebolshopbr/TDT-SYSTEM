# Memoria TDT: empieza aquí

Esta carpeta es el punto de orientación para cualquier IA o persona que trabaje en TDT NUEVO.
Si no sabes dónde está algo, qué se decidió o dónde guardar lo que hiciste, léela primero.

## Orden de lectura

1. `AGENTS.md` (raíz): reglas del proyecto. Tienen prioridad sobre esta carpeta.
2. `mapa.md`: qué hay en cada carpeta, direcciones locales, dominios, logins y bases de datos.
3. `estado.md`: qué está hecho y qué está pendiente en cada proyecto.
4. `decisiones.md`: decisiones de TT con fecha. No se discuten de nuevo sin que TT lo pida.
5. `bitacora.md`: últimos cambios, del más nuevo al más viejo.
6. `revision.md`: qué material viejo hay en `~/TDT_REVISION` y dónde está.

## Dónde guardar

| Qué | Dónde |
|---|---|
| Una decisión nueva de TT | `decisiones.md`, con fecha y palabras de TT si las hay |
| Un cambio terminado | `bitacora.md`, con la fecha, qué se hizo y en qué archivos, en una entrada breve |
| Algo terminado o pendiente | `estado.md`, actualizando el proyecto que corresponde |
| Una carpeta, URL o base de datos nueva | `mapa.md` |
| Código o archivos de un proyecto | en la carpeta de ese proyecto (`GLOBAL/`, `GROWTH/`, `DIGITAL/`), nunca aquí |
| Material viejo o dudoso | `~/TDT_REVISION/<nombre>-AAAA-MM-DD/`, nunca se borra. Anotarlo en `revision.md` |

## Reglas de esta carpeta

- Solo texto. Nunca contraseñas, tokens, claves secretas ni `service_role`.
- Separar HECHO (verificado), PROPUESTA y PENDIENTE. Declarado no equivale a verificado.
- Si algo aquí contradice el código, el código manda: corrige esta carpeta y anótalo en la bitácora.
- Fechas absolutas (AAAA-MM-DD), nunca "ayer" o "la semana pasada".
- Escribir en español. La interfaz para los socios de Global va en portugués de Brasil.
